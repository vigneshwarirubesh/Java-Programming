# Java Programming Practice Journey ☕

Welcome to my **Java-Programming** repository! This repository documents my 5-day hands-on Java coding journey in **Eclipse IDE**, progressing systematically from core syntax, operators, and loops to arrays, strings, methods, and Object-Oriented Programming (OOP) principles.

---

## 📂 Repository Structure & Day-Wise Breakdown

### 📁 `day1/` — Java Fundamentals, Variables & Operators
Focuses on Java syntax basics, user input with `Scanner`, data types, and fundamental operators:
* **Variables & I/O:** `EgPrintandPrintln.java`, `InitializingVariable.java`, `RedeclaringVariable.java`, `EgNotGivingAnyValueforVariable.java`, `GreetingMessageDisplay.java`, `SumAverageUsingScanner.java`

### 📁 `day2/` — Loops, Number Logic & Basic Arrays
Focuses on iterative logic, mathematical number checks, and introductory array handling:
* **Number Theory & Loops:** `AllFactorsOfNum.java`, `AllNumDivBy5btw103and206.java`, `AmstrongNum.java`, `CheckFactorsAndPrime.java`, `EvenNumBtw100and200.java`, `FactorialOfNum.java`, `HarshadNumber.java`, `PerfectNum.java`, `StrongNumber.java`, `SumOfNumDivbyBoth3and5.java`

### 📁 `day3/` — Control Flow, Strings, Searching & Static Methods
Focuses on string manipulation, binary search, conditional branching, and modular methods:
* **Conditionals & Switch:** `CategorizePersonsOnDiffAgeGroup.java`, `LargestNumUsingNestedIf.java`, `LargestUsingTernaryOperator.java`, `LeapYear.java`, `SwitchCaseForNumOfDaysInMonth.java`

### 📁 `day4/` — Methods, Constructors & Algorithmic Problem Solving
Focuses on writing reusable methods, constructors, and string/number algorithms:
* **Constructors & Methods:** `EgOfConstructor.java`, `ProfitPercentageUsingMethod.java`, `SumOfNumDivbyBoth3and5UsingMethod.java`, `UsingMethodCurtains.java`, `UsingMethodDistancebtwAdjacentNum.java`

### 📁 `day5/` — Object-Oriented Programming (OOP) & Collections
Focuses on core OOP pillars—inheritance, polymorphism, abstraction, interfaces—and `ArrayList` collections:
